# cofactor o adjunto
#matrices 

>[!abstract] definición
>teniendo una [[matriz cuadrada]] $A$, el [[menor complementario]] de un elemento $a_{ij}$ en $A$ o el opuesto de este dependiendo de si $i+j$ es par o impar, respectivamente.

denotado como $A_{ij}$, podemos definirlo como:
$$\large A_{ij}=(-1)^{i+j}\cdot M_{ij}$$
- no confundir con $A_{(i,j)}$, que se usa para denotar la [[matriz adjunta de un elemento]].

los adjuntos de los elementos de $A$ se utilizan para construir la [[matriz adjunta]].
