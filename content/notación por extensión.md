# notación por extensión

>[!abstract] definición
>una forma de describir un [[conjunto]], escribiendo cada elemento en una lista entre llaves $\{\}$.

esta notación es especialmente útil cuando el conjunto es finito y con pocos elementos. 

esto no significa que no se pueda usar para conjuntos infinitos o extensos. cuando los elementos tienen un patrón claro, se puede usar tres puntos ($\dots$) para acortarlo.
- también se pueden usar en el comienzo y/o final de un conjunto infinito. 

algunos ejemplos de conjuntos escritos por extensión:
- $\{ a,b,c,d,e \}$
- $\{ \dots,-3,-2,-1,0 \}$
- $\{ 1,2,3,\dots,9,10 \}$
- $\varnothing$ se considera que está escrito por extensión.
