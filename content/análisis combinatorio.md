# análisis combinatorio

>[!abstract] definición
>rama de las matemáticas que estudia la forma de contar, ordenar y seleccionar elementos dentro de un [[conjunto]], considerando las diferentes combinaciones y permutaciones posibles.

## índice
teniendo un conjunto de $m$ elementos, cómo podemos descubrir cuántas combinaciones diferentes de esos elementos se pueden crear?

una forma de descubrirlo manualmente es con un [[diagrama de árbol]], pero no es lo más eficiente.

dependiendo de las condiciones que tenemos, podemos usar diferentes conceptos matemáticos:
- cuando nos importa el orden de nuestros grupos…
	- si sólo vamos a usar *$n$ de nuestros $m$* elementos para cada grupo…
		- [[arreglo simple]]
		- [[arreglo con repetición]]
	- si vamos a usar *todos* nuestros $m$ elementos en cada grupo…
		- [[permutación simple]]
		- [[permutación con repetición]]
- cuando *no* nos importa el orden de los elementos en nuestros grupos…
	- [[combinación simple]]
	- [[combinación con repetición]]

una notación alternativa a la combinación simple es el [[número combinatorio]].
- [[números combinatorios complementarios]]
- [[fórmula de stieffel]]
- [[triángulo de pascal]]

las potencias de un binomio se pueden calcular usando números combinatorios: [[binomio de newton]].
- [[término k-ésimo]]
