# función inversa
#lógica #funciones 

>[!abstract] definición
>teniendo una [[función]] $f:A\to B$, una función inversa mapea elementos de $B\to A$.

simbólicamente, $f:A\to B/y=f(x)\Rightarrow f^{-1}:B\to A/x=f^{-1}(y)$.

la función inversa “deshace” las acciones de la función original. usando la función inversa, podemos empezar por $y$ para volver a $x$.

es importante saber que esto solo aplica para las [[función biyectiva|funciones biyectivas]].
