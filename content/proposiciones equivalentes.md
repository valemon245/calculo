# propiedades de las proposiciones
#lógica 

>[!abstract] definición
>dos [[proposición lógica|proposiciones]] cuyas [[tablas de verdad]] son iguales.

usamos $\equiv$ para decir que dos proposiciones son lógicamente equivalentes. nótese que si reemplazamos $\equiv$ con $\Leftrightarrow$, creamos una [[tautología]].

algunas equivalencias útiles:

| nombre                             | simbolización                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| involución o doble negación        | $\neg \left( \neg p\right) \equiv p$                                                                                                                                                                                                                                                                                                          |
| conmutativa                        | $p\wedge q\equiv q\wedge p$<br>$p\vee q\equiv q\vee p$                                                                                                                                                                                                                                                                                        |
| asociativa                         | $p\wedge \left( q\wedge r\right) \equiv \left( p\wedge q\right) \wedge r$<br>$p\vee \left( q\vee r\right) \equiv \left( p\vee q\right) \vee r$                                                                                                                                                                                                |
| distributiva                       | $p\wedge \left( q\vee r\right) \equiv \left( p\wedge q\right) \vee \left( p\wedge r\right)$<br>$p\vee \left( q\wedge r\right) \equiv \left( p\vee q\right) \wedge \left( p\vee r\right)$                                                                                                                                                      |
| idempotencia                       | $p\wedge p\equiv p$<br>$p\vee p\equiv p$                                                                                                                                                                                                                                                                                                      |
| leyes de De Morgan                 | $\neg \left( p\wedge q\right) \equiv \left( \neg p\right) \vee \left(\neg q\right)$<br>$\neg \left( p\vee q\right) \equiv \left( \neg p\right)\wedge \left(\neg q\right)$                                                                                                                                                                     |
| absorción                          | $p\land(p\lor q)\equiv p$<br>$p\vee (p\wedge q)\equiv p$<br>$p\vee(\neg p\wedge q)\equiv p\vee q$<br>$p\wedge(\neg p\vee q)\equiv p\wedge q$                                                                                                                                                                                                  |
| identidad                          | $p\wedge V\equiv p$<br>$p\vee F\equiv p$                                                                                                                                                                                                                                                                                                      |
| dominación                         | $p\vee V\equiv V$<br>$p\wedge F\equiv F$                                                                                                                                                                                                                                                                                                      |
| bicondicional                      | $$\begin{align}p\Leftrightarrow q & \equiv \left( p\Rightarrow q\right) \wedge \left( q\Rightarrow p\right) \\ & \equiv \left( \neg p\vee q\right) \wedge \left( \neg q\vee p\right) \\ & \equiv \left( \neg p\wedge \neg q\right) \vee \left( p\wedge q\right) \\ & \equiv -\left( p\vee q\right) \vee \left( p\wedge q\right) \end{align}$$ |
| disyunción excluyente              | $\begin{align}p\veebar q&\equiv (p\vee q) \wedge \neg(p\wedge q)\\&\equiv \neg(p \Leftrightarrow q)\end{align}$                                                                                                                                                                                                                               |
| implicación como disyunción        | $p\Rightarrow q\equiv (\neg p)\vee q$                                                                                                                                                                                                                                                                                                         |
| negación de la implicación         | $\neg(p\Rightarrow q)\equiv p\wedge (\neg q)$                                                                                                                                                                                                                                                                                                 |
| contrarrecíproco de la implicación | $p\Rightarrow q\equiv (\neg q)\Rightarrow (\neg p)$                                                                                                                                                                                                                                                                                           |
| tercero excluido                   | $p\vee (\neg p)\equiv V$                                                                                                                                                                                                                                                                                                                      |
| contradicción                      | $p\wedge (\neg p)\equiv F$                                                                                                                                                                                                                                                                                                                    |
| simplificación                     | $p\wedge q\Rightarrow p\equiv V$                                                                                                                                                                                                                                                                                                              |
| adición                            | $p\Rightarrow p\vee q\equiv V$                                                                                                                                                                                                                                                                                                                |
| modus ponens                       | $[(p\Rightarrow q)\wedge p]\Rightarrow q\equiv V$                                                                                                                                                                                                                                                                                             |
| silogismo hipótetico               | $[(p\Rightarrow q)\wedge(q\Rightarrow r)]\Rightarrow(p\Rightarrow r)\equiv V$                                                                                                                                                                                                                                                                 |

## por qué proposiciones equivalentes?
conocer las léyes lógicas nos sirve para realizar simplificaciones en proposiciones compuestas.
