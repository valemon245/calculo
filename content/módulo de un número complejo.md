# módulo de un número complejo

>[!abstract] definición
>en el plano complejo, la distancia o longitud del vector de un [[números complejos|número complejo]] desde el punto de origen.

si $z=(a,b)$, entonces su módulo se define como:
$$\large |z| = \sqrt{a^{2}+b^{2}}$$

## propiedades
- el módulo de $z$ es 0 si y sólo si $z=0$.
- el módulo de un número complejo real es su valor absoluto.
- el módulo de $z=(1,1)$ es $\sqrt{ 2 }$.
