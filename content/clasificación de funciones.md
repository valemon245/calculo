# clasificación de funciones
#lógica #conjuntos 

>[!abstract] definición
>diferentes clasificaciones posibles para las [[función|funciones]].

las funciones pueden ser…
- [[función inyectiva|inyectivas]], si todos los elementos $x$ tienen distinta imagen. 
- [[función suryectiva|suryectivas]], si todos los elementos $y$ tienen al menos una $x$ asociada.
- [[función biyectiva|biyectivas]], si son inyectivas y suryectivas.
	- se puede hallar su [[función inversa]].

no confundir con [[clasificación de relaciones definidas en un conjunto]].
