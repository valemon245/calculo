# repetición condicional
#programación 

>[!abstract] definición
>comando especial que realiza una secuencia de comandos una y otra vez hasta que una condición se cumpla.

herramienta del lenguaje dentro del [[marco conceptual enfocado en la abstracción para aprender a programar]].

la repetición condicional es útil cuando no sabemos cuántas veces necesitamos repetir una acción, cuando tenemos un escenario cambiante. una vez identificada una condición que podamos verificar, se usa como señal para que el comando se detenga.

es un tipo de *bucle* al igual que la [[repetición simple]].

saber sobre [[recorrido|recorridos]] es útil para comenzar a usar la repetición condicional.
