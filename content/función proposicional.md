# función proposicional

>[!abstract] definición
>una [[proposición lógica|proposición]] que contiene una o más variables y cuyo valor de verdad dependerá del valor que tomen dichas variables.

a las funciones proposicionales también se les llama predicado (*predicate* en inglés). 

una definición alternativa puede ser que las funciones proposicionales son una [[función]] cuyo [[codominio]] es el [[conjunto]] de booleanos $\{ \text{verdadero}, \text{falso} \}$. 

las funciones proposicionales suelen representarse usando notación de función, donde se escriben las variables dentro de un paréntesis seguido de una letra.
- por ejemplo, $P(x,y): x\text{ es mayor que } y$.

para obtener proposiciones de una función proposicional utilizamos la [[cuantificación]], asignándole un [[dominio de la relación|dominio]] del cual tomar sus variables o argumentos.

## relacionado
- las funciones proposicionales se usan en el [[principio de inducción completa]].

## por qué función proposicional?
yo creo que las funciones proposicionales son útiles principalmente para crear afirmaciones sobre ciertos objetos, lo cual sirve para formular teoremas, por ejemplo.
