# diagrama de árbol
#matematica 

>[!abstract] definición
>diagrama para descubrir las posibles combinaciones de $m$ elementos.

digamos que tenemos los dígitos $1,2,3,4,5$. sin repetirlos, cuántos números diferentes de 3 cifras podríamos crear con ellos?

![[alg_diagrama12345.png]]

para la primera cifra tenemos 5 posibilidades; 4 para la segunda (ya que no se pueden repetir los elementos), y finalmente 3 opciones para la última cifra. 

una forma más eficiente de calcular esto es con un [[arreglo simple]].
