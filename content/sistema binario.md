# sistema binario

>[!abstract] definición
>sistema de numeración que representa información usando 2 cifras.

también llamado sistema diádico, es importante dentro de la [[ciencias de la computación|informática]] ya que es el sistema utilizado dentro de las computadoras. por su arquitectura, la computadora solo trabaja con dos estados: encendido (hay voltaje eléctrico) y apagado (no hay voltaje).

las cifras usadas en el sistema binario suelen ser el *cero* y el *uno*. nótese que se técnicamente se podrían usar otras cifras, pero el cero y el uno son las que se ven en el [[código binario]].
- el código binario no es lo mismo que el sistema binario.

el sistema binario es un [[sistema de numeración posicional]]. ya que dispone de dos cifras decimos que es de *base 2*.
