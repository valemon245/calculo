# conjunto universal
#lógica #conjuntos 

>[!abstract] definición
>el [[conjunto]] de todos los elementos que se están utilizando en un contexto dado.

es útil para limitarnos a hablar solo de los elementos que necesitamos, por eso también se le llama conjunto referencial.

se representa con una U, particularmente $\mathcal{U}$. se puede definir usando $\mathcal{U}=\{x/x=x\}$. 

$\mathcal{U}$ suele ser obvio basándonos en el contexto, pero a veces es necesario clarificar cuál es el conjunto referencial con el que estamos trabajando.
